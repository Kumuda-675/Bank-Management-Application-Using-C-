# Bank Management Application

## Files
- `bank_management.cpp` - Complete C++ source code
- `bank_data.txt` - Customer records file (created automatically)
- `README.md` - Project instructions

## Features
1. Create Account
2. Login to Account
3. Deposit Money
4. Withdraw Money
5. Check Balance
6. Display Account Details
7. Persistent data storage using file handling

## Compile

Open a terminal in the project folder and run:

```bash
g++ bank_management.cpp -o bank_management
```

## Run on Windows

```bash
.\bank_management.exe
```

## Run on Linux/macOS

```bash
./bank_management
```

The program automatically creates `bank_data.txt` and saves account records.
